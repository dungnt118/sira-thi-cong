# UI/UX Blueprint - Supervisor

## Mục tiêu vai trò

Supervisor chịu trách nhiệm điều phối hiện trường, kiểm soát chất lượng và làm cầu nối giữa PM với Worker.

## Màn hình bắt buộc

- Danh sách dự án phụ trách
- Task board hiện trường
- Checklist theo task
- Review evidence tại hiện trường
- Incident center
- Acceptance form
- Maintenance visit form
- Site synthesis report

## Flow chính

1. Nhận task từ PM
2. Điều phối Worker
3. Theo dõi bằng chứng/checklist
4. Báo cáo sự cố và xử lý vướng mắc
5. Tạo biên bản nghiệm thu
6. Ghi nhận bảo dưỡng định kỳ

## Gap còn thiếu trong hiện trạng

- Code đang lẫn giữa `Supervisor` và `Worker`
- Chưa có task board riêng cho Supervisor
- Chưa có acceptance và maintenance workflow thật
