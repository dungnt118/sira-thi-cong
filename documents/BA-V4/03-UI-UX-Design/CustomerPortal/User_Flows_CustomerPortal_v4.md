# User Flows - Customer Portal v4

## 1. Flow truy cập portal

1. BAC phát hành link portal cho khách hàng.
2. Khách xác thực và vào `Project Overview`.
3. Hệ thống chỉ hiển thị công trình và dữ liệu được cấp quyền.

## 2. Flow xem tiến độ và minh chứng

1. Khách mở `Progress Timeline`.
2. Khách chọn một mốc thi công.
3. Hệ thống hiển thị ảnh/video/file đã duyệt.
4. Nếu khách cần hỏi thêm, khách mở thread trao đổi ngay từ mốc đó.

## 3. Flow chat làm bằng chứng

1. Khách mở `Chat Inbox` hoặc thread gắn với mốc/case.
2. Khách gửi câu hỏi hoặc phản hồi.
3. `Sale/PM/Giám sát/Kế toán` trả lời theo thẩm quyền.
4. Hệ thống lưu read receipt, thời gian phản hồi và file đính kèm.

## 4. Flow bảo hành/bảo trì

1. Khách chọn `Warranty/Maintenance Request`.
2. Nhập mô tả hiện trạng và tải ảnh/video.
3. Hệ thống tạo case nội bộ.
4. BAC phản hồi lịch xử lý và cập nhật trong thread tương ứng.

## 5. Flow xem chứng từ và thanh toán

1. Khách mở `Document Center` hoặc `Payment Milestones`.
2. Xem đề nghị thanh toán, biên bản, bảo hành đã phát hành.
3. Nếu có thắc mắc, khách mở thread `PAYMENT` hoặc `ACCEPTANCE`.
