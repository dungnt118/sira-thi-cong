# UI/UX Blueprint - PM

## Mục tiêu vai trò

PM là vai trò trung tâm, vừa chịu trách nhiệm sale, vừa chịu trách nhiệm vận hành đầu-cuối.

## Màn hình bắt buộc

- Dashboard PM theo `Service Request` và `Project`
- Customer hub
- Service Request list/detail
- Pipeline Kanban
- Survey form
- Quotation workspace
- Contract/Project conversion
- Project workbench
- Task board đa vai trò
- Material plan
- Finance snapshot
- Portal publish

## Flow chính

1. Tạo `Service Request`
2. Khảo sát và lập báo giá
3. Chốt báo giá/hợp đồng
4. Convert thành dự án
5. Điều phối task, vật tư, review bằng chứng
6. Nghiệm thu, theo dõi thanh toán, bảo hành

## Gap còn thiếu trong hiện trạng

- Chưa có task board chuẩn
- Điều hướng PM còn rời rạc giữa CRM/Construction/Inventory/Finance
- Chưa có luồng convert chuẩn từ quote sang contract/project
- Chưa có change order và nghiệm thu hoàn chỉnh
