# User Documentation Seed - Worker

## Mục tiêu tài liệu

Worker cần tài liệu ngắn, trực quan, ưu tiên mobile:

- xem việc
- ký nhận vật tư
- làm checklist
- chụp/upload ảnh
- báo sự cố

## Tài liệu cần biên soạn

- Quick start cho Worker
- Hướng dẫn chụp ảnh đúng chuẩn
- Hướng dẫn xử lý khi bị reject
- Hướng dẫn báo sự cố
