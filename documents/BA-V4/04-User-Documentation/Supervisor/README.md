# User Documentation Seed - Supervisor

## Mục tiêu tài liệu

Supervisor cần tài liệu ngắn gọn, thiên về flow hiện trường và nhấn mạnh rằng đây là actor số chính trên hệ thống trong phase hiện tại.

## Tài liệu cần biên soạn

- Quick start cho Supervisor
- Hướng dẫn nhận task và gắn worker profile
- Hướng dẫn ký nhận/phát vật tư
- Hướng dẫn cập nhật checklist, evidence, sự cố thay mặt worker profile
- Hướng dẫn nghiệm thu
- Hướng dẫn maintenance/warranty visit
- Hướng dẫn xử lý khi file sync lỗi

## Điểm cần nhấn mạnh trong tài liệu

- luôn chọn đúng worker profile khi thao tác hộ
- không đóng task khi vật tư hoặc evidence chưa đủ
- không publish hồ sơ khách hàng khi file chưa sync/approve
