# User Documentation Seed - Supervisor

## Mục tiêu tài liệu

Supervisor cần tài liệu ngắn gọn, thiên về flow hiện trường:

- nhận việc
- theo dõi task
- kiểm soát bằng chứng
- nghiệm thu
- bảo dưỡng

- Quick start cho Supervisor
- Hướng dẫn duyệt hiện trường
