# User Documentation Seed - Admin

## Mục tiêu tài liệu

Tài liệu người dùng cho Admin ở giai đoạn go-live cần bao phủ:

- tạo user/role
- cấu hình pipeline/playbook
- cấu hình master data
- xem audit
- xuất báo cáo quản trị

Lưu ý: `Admin` trong folder này là vai trò quản trị hệ thống, khác với `HanhChinh` là vai trò vận hành hồ sơ nghiệp vụ.

## Tài liệu cần biên soạn

- Quick start cho Admin
- Checklist cấu hình hệ thống ban đầu
- Hướng dẫn audit log
- Hướng dẫn quản trị report và notification
