# User Documentation - Sale

## Mục tiêu

Bộ tài liệu này giúp Sale vận hành thống nhất trên hệ thống:

- không bỏ sót lead
- không trễ follow-up
- không gửi sai tài liệu
- không mất dấu hợp đồng/tạm ứng/thanh toán
- có quy trình chăm sóc sau công trình

## Tài liệu trong folder này

- `Operating_Guide_Sale_v4.md`

## Nguyên tắc sử dụng

1. Mọi giao tiếp quan trọng với khách phải có dấu vết trên hệ thống.
2. Mọi báo giá/hợp đồng/chứng từ gửi khách phải bám vào version tài liệu hợp lệ.
3. Không dùng chat ngoài luồng làm nguồn sự thật duy nhất cho tiến độ deal.
