# User Documentation - HanhChinh

## Mục tiêu

Bộ tài liệu này hướng dẫn Hành Chính vận hành hồ sơ số thống nhất:

- phát hành đúng mẫu
- gửi đúng người
- lưu đúng hồ sơ
- không thất lạc trạng thái ký hoặc trạng thái giao nhận

## Tài liệu trong folder này

- `Operating_Guide_HanhChinh_v4.md`

## Nguyên tắc sử dụng

1. Không phát hành tài liệu ngoài luồng nếu chưa kiểm tra version mẫu.
2. Không đánh dấu hoàn tất nếu chưa có file đã phát hành hoặc đã ký.
3. Mọi mail/chứng từ gửi ra ngoài đều phải có log trên hệ thống.
