# Accountant - User Documentation V4

## 1. Mục tiêu

Folder này mô tả cách vai trò `Accountant` vận hành hệ thống theo bối cảnh nghiệp vụ thật, không đi theo menu rời rạc.

## 2. Tài liệu hiện có

- `Operating_Guide_Accountant_v4.md`: hướng dẫn vận hành hằng ngày, theo từng kịch bản thực tế

## 3. Phạm vi vận hành mà Accountant phải nắm

- quản lý đợt thanh toán và xác nhận thu tiền
- ghi nhận chi phí công trình và kiểm soát chi tiền
- vận hành sổ quỹ, nguồn tiền công ty/cá nhân/quỹ tiền mặt
- quản lý phiếu kho và ký nhận vật tư
- theo dõi chi phí hậu mãi, billing bảo trì, retention
- phát hành và lưu hồ sơ tài chính số

## 4. Ghi chú

Nếu sau này cần mở rộng tiếp cho rollout và UAT, package Accountant nên bổ sung thêm:

- checklist chốt tháng
- checklist đối soát quỹ
- hướng dẫn phát hành hồ sơ thanh toán số
