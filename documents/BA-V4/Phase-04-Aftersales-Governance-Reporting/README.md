# Phase 4 - Aftersales, Governance & Reporting

## 1. Mục tiêu phase

Phase 4 đóng vòng hệ thống ở lớp:

- hậu mãi
- governance
- báo cáo
- hardening trước rollout lớn

## 2. Vai trò trung tâm

- `PM`
- `Sale`
- `Giám sát`
- `Kế toán`
- `Admin`
- `Customer Portal`

## 3. Cấu trúc chức năng chi tiết

### 3.1 Warranty & Maintenance Lifecycle

- warranty card
- warranty case
- maintenance visit
- aftersales cost
- aftersales billing
- coverage result

### 3.2 Portal Completion

- portal timeline đầy đủ
- portal document center đầy đủ
- portal payment thread
- portal warranty request
- communication dossier

### 3.3 Governance & Audit

- audit log đầy đủ
- notification rule engine
- file sync monitoring
- permission hardening
- template governance

### 3.4 Reporting

- project health dashboard
- conversion dashboard
- cost/margin dashboard
- aftersales dashboard
- inventory valuation
- management KPI

### 3.5 Rollout Readiness

- UAT hoàn chỉnh
- pilot support
- training package
- migration checklist

## 4. Deliverable chính của phase

- warranty/maintenance vận hành được
- portal hậu mãi và communication evidence hoàn chỉnh
- dashboard quản trị và audit
- bộ tiêu chí rollout

## 5. Ngoài phạm vi phase

- ERP tổng thể
- HR/payroll
- AI automation nâng cao
- mobile app native riêng

## 6. Tiêu chí hoàn tất phase

- [ ] Warranty/maintenance có financial impact rõ
- [ ] Portal giao tiếp trở thành bằng chứng chính thức
- [ ] Audit và reporting đủ cho pilot mở rộng
- [ ] Có checklist rollout và hardening
