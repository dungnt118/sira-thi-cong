Table Columns Details:
- Name: Customer name (sortable, clickable → detail page)
- Type: Corp(orate) / Indv(idual) (filterable)
- Contact: Phone + Email (click to call/email)
- Projects: Count of projects (clickable → filtered project list)
- Value: Total contract value in VND (sortable)
- Status: ACTIVE / INACTIVE badge (filterable)
- Actions: Dropdown menu

Legend:
- [✓] ACTIVE = Green (has active contracts/projects)
- [⏳] INACTIVE = Gray (no active contracts/projects)
- Corp = Corporate customer
- Indv = Individual customer
