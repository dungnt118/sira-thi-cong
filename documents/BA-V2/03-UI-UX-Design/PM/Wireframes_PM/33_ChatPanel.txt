NOTES:
------
1. ChatPanel Features:
   - Real-time messaging (WebSocket hoặc long polling)
   - File attachment với drag-and-drop
   - Auto-save to project gallery
   - @Mention để tag người
   - Pin important messages
   - Create task from message
   - Search và filter messages
   - Emoji support
   - Voice recording (optional)

2. Integration với Features khác:
   - Ảnh uploaded → Auto vào Evidence Gallery
   - @Mention → Send notification
   - Create task → Link to Task Management
   - Pin → Quick access sidebar

3. File Types Support:
   - Images (JPG, PNG, GIF)
   - Videos (MP4, MOV)
   - Documents (PDF, DOC, DOCX)
   - CAD files (DWG, DXF)
   - Spreadsheets (XLS, XLSX)
   - Max file size: 10MB per file

4. Responsive:
   - Desktop: 3-column layout (Chat | Members | Attachments)
   - Mobile: Stack vertically, swipe between sections

5. Notifications:
   - Desktop push notification
   - Email digest (configurable)
   - Mobile app push (nếu có)
   - Badge count trên tab

6. Privacy:
   - Chỉ thành viên dự án mới thấy
   - Admin PM có thể mute/remove người
   - Message có thể edit trong 5 phút
   - Delete chỉ hide, không xóa hẳn (audit trail)

7. System Messages:
   - Milestone completed
   - Staff joined/left
   - Document uploaded
   - Status changed
