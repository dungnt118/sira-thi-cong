Table Columns Details:
- Name: Member name + contact icons (📧 email, 📞 phone)
- Role: PM / Supervisor / Staff
- Dept: Department abbreviation
- Projects: Count + status (Active/Bench)
- Avail: Availability percentage (100% = fully available)
- Skills: Skill tags (abbreviated)
- Status: ACTIVE / ON_LEAVE / INACTIVE badge
- Actions: Dropdown menu

Availability Legend:
- 100% = Available (green)
- 60-99% = Partially available (yellow)
- 0-59% = Mostly assigned (orange)
- 0% = Fully allocated (red)
