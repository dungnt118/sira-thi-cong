# Wireframes - Project Manager (PM) Interface

This folder contains low-fidelity wireframes for the PM role interface.

---

## 🎯 Wireframe Index

### 1. Dashboard & Navigation
- `01_Dashboard.txt` - Dashboard overview with KPIs, charts, recent items
- `02_Top_Navigation.txt` - Top bar with search, notifications, profile
- `03_Side_Menu.txt` - Side navigation menu structure

### 2. Project Management
- `04_Project_List.txt` - Project listing table
- `05_Project_Create_Internal.txt` - Create project form (internal scenario)
- `06_Project_Create_Outsource.txt` - Create project form (outsource scenario)
- `07_Project_Detail_Overview.txt` - Project detail page (overview tab)

### 3. Evidence Management
- `08_Evidence_Gallery.txt` - Evidence gallery with filters
- `09_Evidence_Lightbox.txt` - Evidence fullscreen view with approve/reject

### 4. Financial Tracking
- `10_Financials_Tab.txt` - Financials tab with milestones table
- `11_Add_Milestone_Modal.txt` - Add payment milestone form

### 5. Customer Portal
- `12_Portal_Management.txt` - Portal link management table
- `13_Generate_Link_Modal.txt` - Generate portal link modal
- `14_Link_Success_Modal.txt` - Success modal with copy + QR

---

## 📐 Wireframe Format

All wireframes are **text-based ASCII art** for quick iteration.

**Symbols used**:
```
┌─┐└┘├┤┬┴│─  = Borders
[ Button ]    = Clickable buttons
[Dropdown ▼]  = Dropdown selects
[Search 🔍]   = Search inputs
[Icon]        = Icons
✓ ✗ ⏳       = Status indicators
```
