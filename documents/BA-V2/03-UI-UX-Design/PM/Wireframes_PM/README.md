# Wireframes - Project Manager (PM) Interface

This folder contains comprehensive low-fidelity wireframes for the PM role interface covering all operational features.

---

## 🎯 Wireframe Index

### 1. Dashboard & Overview (3 wireframes)
- `01_Dashboard.txt` - Dashboard with KPIs, charts, recent projects, quick actions
- `02_Project_List.txt` - Project list with filters, card/list/timeline views, bulk actions
- `03_Project_Detail_Overview.txt` - Project detail overview tab (internal & outsource types)

### 2. Evidence Management (1 wireframe)
- `08_Evidence_Gallery.txt` - Evidence gallery with filters, thumbnails, lightbox view

### 3. Project Creation (1 wireframe)
- `05_Project_Create_Internal.txt` - Create internal project form

### 4. Financial Management (1 wireframe)
- `10_Financials_Tab.txt` - Financials tab with milestones table, cost breakdown

### 5. Customer Portal (1 wireframe)
- `13_Generate_Link_Modal.txt` - Generate portal link modal with access control

### 6. Contract Management (3 wireframes)
- `15_Contract_List.txt` - Contract list with filters, table, summary stats
- `16_Contract_Create.txt` - Create/Edit contract form with milestones, attachments
- `25_Contract_Detail.txt` - Contract detail page with projects, payments, documents tabs

### 7. Customer Management (3 wireframes)
- `19_Customer_List.txt` - Customer list with filters, table, summary stats
- `20_Customer_Detail.txt` - Customer detail page with projects, contracts, activity
- `21_Customer_Create.txt` - Add/Edit customer form (corporate & individual types)

### 8. Resource Planning (2 wireframes)
- `17_Material_Planning.txt` - Material planning with usage tracking, variance analysis
- `18_Labor_Planning.txt` - Labor planning with allocation by role, cost breakdown, timesheets

### 9. Team & Outsource Management (2 wireframes)
- `22_Team_Management.txt` - Team member list with capacity overview, assign modal
- `23_Outsource_Management.txt` - Outsource company management with performance metrics

### 10. Reports & Analytics (1 wireframe)
- `24_Reports_Analytics.txt` - Reports center with quick reports, custom builder, sample output

### 11. Settings & System (3 wireframes)
- `26_Settings.txt` - Settings with 6 tabs (Profile, Notifications, Display, Security, API, Team Preferences)
- `27_Activity_Log.txt` - Activity log/audit trail with filters, timeline, export
- `28_Notifications.txt` - Notifications center with priority levels, actions

## 📐 Wireframe Format

All wireframes are **text-based ASCII art** for quick iteration and comprehensive coverage.

**Symbols used**:
```
┌─┐└┘├┤┬┴│─  = Borders
[ Button ]    = Clickable buttons
[Dropdown ▼]  = Dropdown selects
[Search...]   = Search inputs
🔔 📋 💰      = Icons
✓ ✗ ⏳       = Status indicators
```
