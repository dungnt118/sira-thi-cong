LAYOUT NOTES:

1. TOP BAR (56px height)
   - Back button (left): Return to project detail
   - Title: "Evidence"
   - Search icon (right): Search by note/date
   - More menu (far right): 
     - Download all
     - Share evidence
     - Filter options

2. STAGE FILTER TABS (48px height, horizontal scroll)
   - Tất cả (24): All evidence with count
   - BEFORE (5): Before photos
   - DURING (15): During photos
   - AFTER (4): After photos
   - Active tab: Primary-500 + bottom border
   - Inactive: Gray-600

3. STATUS FILTER TABS (48px height, horizontal scroll)
   - Tất cả: All status
   - Chờ duyệt (3): Pending approval
   - Đã duyệt (21): Approved
   - Bị từ chối (0): Rejected
   - Active tab: Primary-500 + bottom border
   - Badge colors:
     - Pending: Orange
     - Approved: Green
     - Rejected: Red

4. DATE GROUPS
   - Group by date: Hôm nay | Hôm qua | DD/MM/YYYY
   - Group header: 14px, Gray-700, semibold
   - Count in parentheses
   - Spacing: 16px margin top

5. IMAGE GRID (3 columns)
   - Image card:
     - Thumbnail: Square (110x110px)
     - Stage badge: Top left overlay
       - BEFORE: Blue-500
       - DURING: Orange-500
       - AFTER: Green-500
     - Status icon: Top right overlay
       - [⏳] Pending: Orange
       - [✓] Approved: Green
       - [✕] Rejected: Red
     - Timestamp: Bottom overlay (HH:mm)
     - Spacing: 4px gap between cards
   - Aspect ratio: 1:1 (square)
   - Border-radius: 8px
   - Tap to view detail

6. FLOATING ACTION BUTTON (FAB)
   - Icon: 📸 Camera
   - Size: 56x56px
   - Position: Bottom right, 16px margin
   - Color: Secondary-500 (Orange)
   - Shadow: 0 4px 8px rgba(0,0,0,0.2)
   - Tap: Open camera for upload

INTERACTIONS:

Tap Image Card:
1. Navigate to detail view
2. Show full image
3. Load metadata
4. Enable swipe navigation

Long Press Image Card:
1. Show context menu:
   - View detail
   - Download
   - Share
   - Delete (if allowed)

Pull to Refresh:
1. Reload evidence list
2. Update counts
3. Show refresh indicator

Pinch on Image:
1. Zoom in/out
2. Pan to view details
3. Double tap to reset

Swipe on Detail View:
1. Swipe left: Next image
2. Swipe right: Previous image
3. Swipe down: Close detail view
