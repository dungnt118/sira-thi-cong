LAYOUT NOTES:

1. TOP BAR (56px height)
   - Menu icon (left): Open side drawer
   - Title: "Danh sách dự án"
   - Search icon (right): Open search interface
   - More menu (far right): Filter, sort options

2. FILTER TABS (48px height, horizontal scroll)
   - Tất cả: All projects
   - Đang làm (5): Active projects with count
   - Đã lên lịch (2): Scheduled projects
   - Hoàn thành (12): Completed projects
   - Active tab: Primary-500 + bottom border
   - Inactive: Gray-600

3. PROJECT CARD (Auto height, min 160px)
   - Header row:
     - Project code (left): 14px semibold
     - Status badge (right): Chip component
   - Project name: 18px semibold, max 2 lines
   - Location: 14px gray with icon
   - Progress bar: 8px height, rounded
     - Fill color based on progress:
       - 0-30%: Error (#F44336)
       - 31-70%: Warning (#FF9800)
       - 71-100%: Success (#4CAF50)
   - Info grid (2 columns):
     - PM name with icon
     - Date range with icon
     - Team size with icon
     - Payment status with icon
   - Padding: 16px
   - Margin-bottom: 16px
   - Shadow: 0 2px 8px rgba(0,0,0,0.1)
   - Border-radius: 8px

4. STATUS BADGES
   - [📝 Nháp]: Gray-200 bg, Gray-800 text
   - [📅 Đã lên lịch]: Blue-100 bg, Blue-800 text
   - [⏳ Đang làm]: Orange-100 bg, Orange-800 text
   - [✓ Hoàn thành]: Green-100 bg, Green-800 text
   - [⚠️ Quá hạn]: Red-100 bg, Red-800 text (with days)
   - Height: 24px
   - Padding: 4px 8px
   - Border-radius: 12px
   - Font-size: 12px

5. INFINITE SCROLL
   - Load 10 projects initially
   - Load 10 more on scroll to bottom
   - Show loading indicator
   - End message when no more projects
