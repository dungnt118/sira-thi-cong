LAYOUT NOTES:

1. TOP BAR (56px height)
   - Back button (left): Return to previous screen
   - Title: "Thông báo"
   - Menu icon (right): More options
     - Mark all as read
     - Clear all notifications
     - Notification settings

2. FILTER TABS (48px height, horizontal scroll)
   - Tất cả: All notifications
   - Chưa đọc (3): Unread only, with badge count
   - Dự án: Project-related
   - Thanh toán: Payment-related
   - Chat: Chat mentions
   - Active tab: Primary-500 color + bottom border
   - Inactive: Gray-600 color

3. NOTIFICATION GROUPS
   - Group by time: Hôm nay | Hôm qua | Tuần trước | Tháng trước
   - Group header: 14px, Gray-700, uppercase
   - Spacing: 24px margin top

4. NOTIFICATION CARD
   - Icon (left): Type indicator (32x32px)
     - 🔔 General
     - 💰 Payment
     - 💬 Chat
     - 🏗️ Project
     - ✅ Approval
     - 📦 Material
     - ⚠️ Warning
   - Read indicator (right): 
     - [●] Unread (Primary-500 dot, 8px)
     - [✓] Read (Gray-400 checkmark)
   - Title: 16px semibold
   - Message: 14px regular, max 2 lines
   - Timestamp: 12px gray, relative time
   - Padding: 16px
   - Border-bottom: 1px solid Gray-200
   - Background: White (unread), Gray-50 (read)

INTERACTIONS:

Tap Notification:
1. Mark as read (if unread)
2. Navigate to related screen
3. Highlight related item (if applicable)
4. Update badge count

Swipe Left (Delete):
1. Show delete button (red background)
2. Tap delete → Remove notification
3. Animate out
4. Update badge count

Swipe Right (Mark as read/unread):
1. Show mark button (blue background)
2. Tap → Toggle read status
3. Update UI
4. Update badge count

Long Press:
1. Show context menu:
   - Mark as read/unread
   - Delete
   - Mute this type
   - Cancel

Pull to Refresh:
1. Pull down from top
2. Show refresh indicator
3. Fetch new notifications
4. Update list

═══════════════════════════════════════════════════════════════════════

BADGE COUNT LOGIC:

Badge Count = Unread notifications count

Update triggers:
- New notification received → +1
- Notification marked as read → -1
- Notification deleted → -1 (if unread)
- Mark all as read → 0
- Clear all → 0

Display:
- 0: Hide badge
- 1-99: Show number
- 100+: Show "99+"

═══════════════════════════════════════════════════════════════════════

FILTER BEHAVIOR:

Tất cả:
- Show all notifications
- Default filter

Chưa đọc (3):
- Show only unread notifications
- Badge shows unread count
- Empty state if no unread

Dự án:
- Show: Project assigned, deadline warning
- Filter by notification type

Thanh toán:
- Show: Payment received, payment request approved/rejected
- Filter by notification type

Chat:
- Show: @Mentions, new messages
- Filter by notification type

═══════════════════════════════════════════════════════════════════════

SETTINGS (via menu icon):

Mark all as read:
- Confirmation dialog
- Update all notifications to read
- Clear badge count
- Update UI

Clear all notifications:
- Confirmation dialog: "Xóa tất cả thông báo?"
- Delete all notifications
- Show empty state

Notification settings:
- Navigate to settings screen
- Configure:
  - Push notification on/off
  - Sound on/off
  - Vibration on/off
  - Notification types to receive
