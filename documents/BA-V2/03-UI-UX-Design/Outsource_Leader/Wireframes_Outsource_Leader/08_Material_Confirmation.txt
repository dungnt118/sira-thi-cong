═══════════════════════════════════════════════════════════════════════

VARIANCE CALCULATION:

Formula:
- Variance = Actual - Planned
- Variance % = (Variance / Planned) × 100%

Display:
- Positive variance: "+5 m (+5%)" (green if <= 10%, yellow if 10-20%, red if >20%)
- Negative variance: "-3 m (-3%)" (same color rules)
- Zero variance: "0 m (0%)" (green)

Color Rules:
- 0-10%: Green (#4CAF50)
- 10-20%: Yellow (#FF9800)
- >20%: Red (#F44336)
