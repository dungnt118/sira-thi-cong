LAYOUT NOTES:

1. TOP BAR (56px height)
   - Menu icon (left): Opens side drawer
   - Logo/Title (center-left)
   - Notification bell (right): Badge count "3"
   - Avatar (far right): 32x32px circle

2. GREETING SECTION (48px height)
   - Welcome message với tên OL
   - Company name subtitle

3. STATS GRID (2x2, 16px spacing)
   - Each card: 
     - Large number (28px bold)
     - Icon + Label (16px)
     - Subtitle (14px gray)
   - Touch target: Full card tappable
   - Navigate to respective screens

4. RECENT PROJECTS SECTION
   - Section header với "Xem tất cả" link
   - Project cards (scrollable vertical list):
     - Code + Status badge (top right)
     - Project name (20px semibold)
     - Location với icon
     - Progress bar (visual indicator)
     - PM name + Date range (14px gray)
     - Status warnings (red for overdue)
   - Card spacing: 16px margin bottom
   - Card shadow: 0 2px 8px rgba(0,0,0,0.1)

5. NOTIFICATIONS SECTION
   - Section header với "Xem tất cả" link
   - Notification cards (compact):
     - Icon (left): Type indicator
     - Title + Message (2 lines)
     - Timestamp (relative: "2 giờ trước")
   - Max 2 notifications shown
   - Tap to navigate to detail

6. BOTTOM TAB BAR (56px height)
   - 4 tabs: Dự án | Upload | Chat | Cá nhân
   - Icon (24x24px) + Label (12px)
   - Active: Primary-500 color
   - Inactive: Gray-600 color
   - Fixed position at bottom

INTERACTIONS:

- Pull-to-refresh: Reload dashboard data
- Tap stat card: Navigate to respective screen
  - Dự án → Project list
  - Evidence → Evidence pending approval
  - Vật tư → Materials to confirm
  - Thanh toán → Payment status
- Tap project card: Navigate to project detail
- Tap notification: Navigate to related screen
- Tap "Xem tất cả": Navigate to full list
- Bottom tabs: Switch between main sections

RESPONSIVE BEHAVIOR:

- Mobile (320-767px): 2-column stats grid
- Tablet (768px+): 4-column stats grid, side-by-side layout

STATUS BADGES:

- [📝 Nháp] = Gray
- [📅 Đã lên lịch] = Blue
- [⏳ Đang làm] = Orange
- [✓ Hoàn thành] = Green
- [⚠️ Quá hạn] = Red (with days overdue)

OFFLINE MODE:

- Show cached data
- Sync indicator at top if offline
- Queue actions (upload, chat) for later sync

PERFORMANCE:

- Lazy load project cards (infinite scroll)
