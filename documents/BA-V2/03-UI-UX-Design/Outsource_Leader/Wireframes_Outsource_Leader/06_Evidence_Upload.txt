CAMERA INTERFACE LAYOUT:

1. CAMERA PREVIEW (Full screen)
   - Native camera feed
   - Aspect ratio: 4:3 or 16:9 (device dependent)
   - Auto-focus on tap
   - Pinch to zoom

2. TOP CONTROLS (Overlay on camera)
   - Close button [✕] (top left):
     - Return to previous screen
     - Confirm if unsaved changes
   - Settings button [⚙️] (top right):
     - Camera quality (Low/Medium/High)
     - Grid lines on/off
     - Auto GPS on/off
   - GPS indicator (center top):
     - "GPS: Đã bật" (green) if enabled
     - "GPS: Tắt" (gray) if disabled
     - Tap to toggle

3. BOTTOM CONTROLS (Overlay on camera)
   - Flash button [🔦] (bottom left):
     - Auto / On / Off
     - Cycle on tap
   - Flip camera button [🔄] (bottom right):
     - Switch front/back camera
   - Stage selector (above capture button):
     - [BEFORE] [DURING] [AFTER]
     - Horizontal tabs
     - Active: Primary-500 bg, white text
     - Inactive: Transparent bg, white text with border
     - Required: Must select before capture
   - Capture button [📸] (center):
     - Large circle button (72x72px)
     - Primary-500 color
     - Tap to capture photo
     - Hold to record video (if enabled)
   - Gallery button [📁] (bottom left of capture):
     - Open device gallery
     - Select existing photo
   - Video button [🎥] (bottom right of capture):
     - Switch to video mode
     - Record video

Preview Screen Elements:

1. TOP BAR
   - Cancel button [✕] (left): Discard and return to camera
   - Confirm button [✓] (right): Proceed to upload

2. IMAGE PREVIEW
   - Full screen preview
   - Pinch to zoom
   - Swipe to view multiple (if batch capture)

3. METADATA DISPLAY
   - Stage: Selected stage (BEFORE/DURING/AFTER)
   - Location: Auto-captured GPS (if available)
   - Timestamp: Auto-captured date/time

4. NOTE FIELD
   - Optional text input
   - Placeholder: "Thêm ghi chú..."
   - Max 500 characters
   - Multiline support

5. ACTION BUTTONS
   - [UPLOAD NGAY]: Primary button
     - Upload immediately
     - Show progress
     - Navigate to evidence gallery on success
   - [Chụp lại]: Secondary button
     - Return to camera
     - Discard current capture
   - [Lưu nháp]: Secondary button
     - Save to local storage
     - Upload later (offline mode)

INTERACTIONS:

Camera Controls:
- Tap to focus
- Pinch to zoom (1x - 10x)
- Double tap to reset zoom
- Swipe up/down to adjust exposure (optional)

Stage Selection:
- Must select before capture
- Highlight selected stage
- Show error if not selected

Capture:
- Tap capture button → Take photo
- Hold capture button → Record video (if enabled)
- Shutter animation
- Capture sound (can be muted)

Preview:
- Pinch to zoom
- Swipe left/right for multiple images
- Tap to show/hide controls

Upload:
- Show progress bar
- Allow cancel
- Retry on failure
- Queue if offline

═══════════════════════════════════════════════════════════════════════

PERFORMANCE:

Image Compression:
- Auto-compress images > 5MB
- Target size: < 1MB for photos
- Quality: 85% JPEG
- Preserve EXIF data (GPS, timestamp)

Video Compression:
- Auto-compress videos > 50MB
- Target bitrate: 2 Mbps
- Resolution: Max 1080p
- Format: MP4 (H.264)

Upload Optimization:
- Compress before upload
- Upload in background
- Resume on network restore
- Batch upload for multiple files

Caching:
- Cache thumbnails locally
- Clear cache after successful upload
- Limit cache size: 100MB
